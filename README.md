# Agro Forte, Futuro Sustentável

## Concurso Agrinho 2026

**Tema:** "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"

---

## Sobre o Projeto

Este projeto foi desenvolvido para o **Concurso Agrinho 2026** com o objetivo de demonstrar como a **tecnologia pode ajudar a agricultura e a pecuária** a aumentar a produção de alimentos ao mesmo tempo em que preserva os recursos naturais e reduz impactos ambientais.

O site conscientiza os visitantes sobre práticas sustentáveis no agronegócio e apresenta soluções tecnológicas reais utilizadas no campo brasileiro.

## Funcionalidades

### 1. Página Inicial (Hero Section)
- Título impactante com animação
- Estatísticas animadas com contadores
- Botões de navegação principais
- Design responsivo com imagem de fundo

### 2. O Desafio Atual
- Cards informativos sobre o crescimento populacional
- Estatísticas reais sobre produção de alimentos
- Dados sobre preservação ambiental

### 3. Tecnologia no Campo
- 6 cards interativos sobre tecnologias agrícolas:
  - Drones Agrícolas
  - Sensores Inteligentes
  - GPS Agrícola
  - Irrigação Automatizada
  - Inteligência Artificial
  - Monitoramento Climático

### 4. Sustentabilidade na Prática
- 6 pilares da sustentabilidade agrícola:
  - Economia de Água
  - Preservação do Solo
  - Redução de Desperdício
  - Agricultura de Precisão
  - Energia Renovável
  - Recuperação de Áreas

### 5. Simulador Inteligente
- Calculadora interativa com validação de entradas
- Campos: área, consumo de água, produção anual, tipo de cultura
- Cálculos:
  - Economia de água
  - Economia de insumos
  - Redução de desperdício
  - Aumento de produção
  - Captura de carbono
  - Economia total estimada

### 6. Quiz Educativo
- 10 perguntas sobre sustentabilidade e tecnologia agrícola
- Feedback imediato com explicações
- Pontuação final com medalhas (Ouro, Prata, Bronze)
- Barra de progresso visual

### 7. Linha do Tempo
- Evolução da agricultura em 6 etapas:
  - Agricultura Tradicional
  - Revolução Verde
  - Plantio Direto
  - Agricultura Digital
  - Agricultura Sustentável
  - Agricultura 5.0 (Futuro)

### 8. Dashboard Interativo
- 3 gráficos com Chart.js:
  - Economia de Água (comparativo)
  - Redução de Emissões (linha do tempo)
  - Crescimento da Produção Sustentável

### 9. Compromisso com o Futuro
- Mensagem inspiradora
- Ícones representativos (Preservar, Reutilizar, Inovar, Educar)

### 10. Rodapé
- Informações do projeto
- Links de navegação
- Fontes e referências
- Link para GitHub

## Acessibilidade

O projeto implementa recursos completos de acessibilidade:

- **Skip Link:** Pula para o conteúdo principal
- **Modo Escuro:** Alternância de tema claro/escuro
- **Alto Contraste:** Tema de alto contraste para deficientes visuais
- **Aumentar/Diminuir Fonte:** Controle de tamanho da tipografia
- **Leitura em Voz Alta:** Web Speech API para leitura do conteúdo
- **ARIA Labels:** Atributos semânticos para leitores de tela
- **Alt em Imagens:** Descrições textuais para todas as imagens
- **Navegação por Teclado:** Suporte completo a Tab e Enter
- **Redução de Movimento:** Respeita `prefers-reduced-motion`
