# 🌾 Agro Forte, Futuro Sustentável
### Concurso Agrinho 2026

Projeto desenvolvido para o Concurso Agrinho 2026, explorando como a tecnologia pode transformar a agricultura e proteger o meio ambiente.

---

## 📄 Sobre o Projeto

Este projeto é uma página web interativa que aborda o tema **agricultura sustentável**, apresentando dados, tecnologias e práticas que estão revolucionando o campo brasileiro.

---

## 🚀 Funcionalidades

- **Hero animado** com estatísticas e cards flutuantes
- **Dashboard interativo** com gráficos de barras, pizza e linha
- **Simulador inteligente** de economia de recursos
- **Quiz educativo** sobre agricultura sustentável
- **Linha do tempo** da evolução da agricultura
- **Cards de tecnologia** expansíveis (drones, sensores, GPS, IA, etc.)
- **Modo escuro** e **acessibilidade** (tamanho de fonte, leitura em voz alta)

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 📁 Estrutura

```
agrinho2026.html   # Arquivo principal (single-page)
README.md          # Documentação do projeto
```

---

## ▶️ Como Executar

Basta abrir o arquivo `agrinho2026.html` diretamente no navegador. Não requer instalação ou servidor.

---

## 🌍 Temas Abordados

- Desafios globais da produção de alimentos
- Tecnologias agrícolas (drones, IoT, IA, GPS)
- Sustentabilidade e preservação ambiental
- Evolução histórica da agricultura
- Energia renovável no campo
